# Data Model: Book Content Structure and Learning Path

This document defines how the book's content structure (modules, chapters) and learning path will be represented.

## Conceptual Model

### Module

A logical grouping of related chapters.

-   **Name**: `string` (e.g., "Introduction to Physical AI")
-   **Slug**: `string` (URL-friendly identifier, e.g., "intro-physical-ai")
-   **Description**: `string` (Optional, brief overview of the module)

### Chapter

A single unit of content within a module. This maps directly to an MDX file.

-   **Title**: `string` (e.g., "What is Physical AI?")
-   **Slug**: `string` (URL-friendly identifier, e.g., "what-is-physical-ai")
-   **File Path**: `string` (Relative path to the MDX file, e.g., `docs/module1/chapter1.mdx`)
-   **Module Slug**: `string` (References the parent module)
-   **Week**: `integer` (References the week in the learning path it belongs to)
-   **Order**: `integer` (Order within its module or week)

### LearningPathWeek

A weekly segment of the learning path, containing a collection of chapters.

-   **Week Number**: `integer` (e.g., 1, 2, 3...)
-   **Theme**: `string` (Optional, e.g., "Foundations of Robotics")
-   **Chapters**: `array<Chapter>` (Collection of chapters assigned to this week)

## Implementation Details (Docusaurus)

The representation of this data model will largely leverage Docusaurus's file-based content management and configuration.

### Modules and Chapters (File System & `sidebars.js`)

-   **Modules**: Represented by directories within the `docs/` folder (e.g., `docs/module-slug/`).
-   **Chapters**: Represented by MDX files within module directories (e.g., `docs/module-slug/chapter-slug.mdx`).
-   **Sidebar Generation**: `sidebars.js` will likely use autogenerated sidebars from these directory structures, with potential manual customization for ordering or grouping.

### Weekly Learning Path (MDX Front Matter & Custom Display)

-   **Chapter Assignment**: Each chapter's MDX file will include `week: <integer>` in its front matter to assign it to a specific week.
    ```mdx
    ---
    title: My Chapter
    week: 1
    ---
    ```
-   **Learning Path Display**:
    -   Option 1: Custom Docusaurus plugin/component that reads all docs metadata (including `week` from front matter) and generates a dedicated "Learning Path" page or a custom section in the sidebar.
    -   Option 2: Manual creation of a sidebar entry in `sidebars.js` that points to a custom React page displaying the weekly breakdown.
    -   The initial approach will focus on parsing the MDX front matter to build the learning path.
